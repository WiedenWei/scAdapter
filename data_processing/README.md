source code for data processing.

get_count_mat_from_h5ad.py - python script to extract cell-gene count matrix from a .h5ad file

get_h5ad_all_expressed.c - c script to get all expressed gene symbol ranked by expression level of all cell (output as comma seperated file, each line is one cell's gene language) from a .h5ad file

remove_housekeeping_genes.py - python script to remove housekeeping gene symbols from each cell's gene language.

tojson_b_subtype.py - python script to transform csv format gene language of each to json format of instruction dataset for b cell subtype.

tojson_dc_subtype.py - python script to transform csv format gene language of each to json format of instruction dataset for DC subtype.

tojson_t_subtype.py - python script to transform csv format gene language of each to json format of instruction dataset for t cell subtype.

tojson_mm_subtype.py - python script to transform csv format gene language of each to json format of instruction dataset for monocyte/macrophage cell subtype.
